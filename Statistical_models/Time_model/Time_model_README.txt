Time_model
This folder includes five R scripts below, one for each site. These scripts fit a hierarchical Bayesian model using the RStan package and the Stan code in the STAN folder. The model include the following predictors:
Year
Ordinal day
Ordinal day²
Year × ordinal day
Year × ordinal day²
No climate variables are included in this model set.
