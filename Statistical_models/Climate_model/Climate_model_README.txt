This folder contain hierarchical Bayesian model fits that include climate covariates, using RStan and the Stan script in the STAN folder. Each model has the following structure:
Year
Ordinal day
Ordinal day²
Climate variable(s)
Climate × ordinal day interactions
Climate × ordinal day² interactions

A forward model-selection approach was used, adding climate variables until an additional variable no longer improved model performance. The subfolder names indicate how many climatic variables were included in the model. Each script name lists the specific seasonal climate variables used.
