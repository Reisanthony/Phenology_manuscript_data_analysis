This folder contains three subfolders, each with five R scripts (one per site). These scripts implement variations of the best-performing model, which includes spring maximum temperature, winter precipitation, and spring minimum temperature as climate predictors. The three subfolders differ only in the data used and the included predictors.


Best_model_with_year
Data: Full dataset (1985–2023)
Predictors:
Year
Ordinal day
Ordinal day²
Climate variables × ordinal day
Climate variables × ordinal day²
Scripts:
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_CASTLE_PEAK.R
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_DONNER_PASS.R
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_LANG_CROSSING.R
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_SIERRA_VALLEY.R
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_WASHINGTON.R

The .rdat files generated by these scripts were used for all downstream analyses, including figure and table generation.



Best_model_with_year_2017

SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_2017_DONNER_PASS.R
SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_2017_LANG_CROSSING.R

SPRINGMAXTEMP_WINTPRCP_SPRINGMINTEMP_ORDDATE_and_YEAR_2017_WASHINGTON.R
